# Real-Time Face Detection App
A computer vision application tthat detects human faces in real-time using a webcam.
## 🔍 What it does
- Opens your webcam and scans for faces in real-time
- Draws a bounding box around every detected face
- Estimates the gender of each detected face
- Estimates the age range of each detected face
- Displays the number of faces detected on screen
## 🛠️ Built With
- Python
- OpenCV
## ⚙️ How to Run
1. Clone the repository
git clone https://github.com/Emmanuel00001/face-detection-app.git
2. Install dependencies
pip install opencv-python
3. Run the app
python face_detection.py
4. Press **Q** to quit
