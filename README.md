# Face Detection & Attendance System
A computer vision application that detects faces, estimates age and gender, 
and runs an automated face recognition attendance system.
## 🔍 What it does
- Detects faces in real-time via webcam
- Estimates gender and age range of detected faces
- Registers known faces by name
- Recognises registered faces automatically
- Logs attendance with name and timestamp to a CSV file
## 🛠️ Built With
- Python
- OpenCV
## ⚙️ How to Run
1. Clone the repository
git clone https://github.com/Emmanuel00001/face-detection-app.git
2. Install dependencies
pip install opencv-python opencv-contrib-python
3. Register your face
python register.py
4. Run the attendance system
python attendance.py
5. Run face detection only
python face_detection.py
